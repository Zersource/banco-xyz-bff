== 4. Conclusion
  RestClient con @LoadBalanced y baseUrl http://cuentas: el host 'cuentas' NO se resuelve por DNS;
  el interceptor de Spring Cloud LoadBalancer lo toma como serviceId, pide las instancias a Eureka
  y elige con RoundRobinLoadBalancer (alternancia estricta request a request, ver logs_replicas.txt).
  El DNS de Docker tambien resolveria 'cuentas' a ambas IPs, pero no es el camino usado: la JVM
  cachea la resolucion DNS y no produciria alternancia estricta por request.
